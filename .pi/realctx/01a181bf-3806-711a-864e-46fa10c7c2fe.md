realtasks reads config only from `<agentDir>/realtasks/config.json` (default `~/.pi/agent/realtasks/config.json`), with an optional override in `.pi/realtasks/config.json` that applies only when `ctx.isProjectTrusted()` is true. Pi's `settings.json` (`tasks` key) is no longer read. Config is loaded at `session_start` (edits apply on `/reload`). Invalid JSON or a non-object file produces one warning (`ctx.ui.notify`, or stderr in print mode) and is ignored. Tests set `PI_CODING_AGENT_DIR` to a temp dir via `writeUserConfig()` in `test/helpers.ts`. For live smoke tests, `--provider uniontech-ai --model deepseek-v4.1-flash` works when the cliproxyapi models fail with TLS/WebSocket errors.
