realtasks recovers and optionally bypasses any `tool_call` hook that mutates `bash` `event.input.command` in place (such as rtk, tokf, or sandbox/wrapper hooks), with no wrapper-specific names or logic:

- Original command recovery lives in `src/rewrite.ts` (`stashCommand`, `commandFromBranch`, `recoverCommand`), checking the `tool_call` stash first and `ctx.sessionManager.getBranch()` second.
- The `bash` tool exposes `rewrite?: "auto" | "off"` (`"off"` runs the original command verbatim).
- `TasksConfig` in `src/config.ts` uses `passthroughFor: string[]` (default `["ready", "tty"]`), edited in `/tasks settings` (`src/settings.ts`) via rows `passthrough.ready` and `passthrough.tty`. Legacy `rtk` / `rtkPassthroughFor` names were removed cleanly without backward-compatibility aliases.
