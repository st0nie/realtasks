The realtasks dock/status spinner (`src/ui.ts` STAR) originally used Claude Code's `·✢✳✶✻✽`. On Windows Terminal `✳` (U+2733, an emoji character with text default) falls back to the color emoji font: a green double-width glyph that also overwrites the next cell (the running count), which looked like flashing. Replaced with `✱` (U+2731). `test/ui.test.ts` asserts the spinner has no `\p{Emoji}` characters; keep all dock/status glyphs out of `\p{Emoji}`.
