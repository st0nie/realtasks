realtasks now pins Pi 1.5.0 (`@earendil-works/pi-coding-agent` and `@earendil-works/pi-tui` peerDependencies, exact `1.5.0`), matching the installed Pi runtime, so 1.5 APIs such as `MessageRenderOptions.keyHint` are used directly without fallbacks.

The peers are installed only through `bun.lock`; after changing the pin, `bun install` keeps the old version, so regenerate with `rm -rf node_modules bun.lock && bun install`. `bun add -d` on a peer does not add a devDependency and reformats package.json.

The task-notification renderer (`renderNotification` in `src/ui.ts`) draws a Pi tool card (`Box` with `toolSuccessBg`/`toolErrorBg`). `CardOptions` in `src/ui.ts` is `Pick<MessageRenderOptions, "expanded" | "outputPad" | "keyHint">` with a required `keyHint` (Pi 1.5 API); there is no optional `CardOptions.keyHint?` field and no fallback to the exported `keyHint`.
