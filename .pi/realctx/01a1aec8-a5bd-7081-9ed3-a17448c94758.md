realtasks type-checks against `node_modules/@earendil-works/pi-coding-agent` 1.4.0 (peer/dev pin), but the installed Pi runtime on this machine is 1.5.0. APIs added in 1.5 are missing from the 1.4 types, for example `MessageRenderOptions.keyHint` (1.4 only has `expanded`, `outputPad`). Make such fields optional and fall back to the 1.4 exports (for example `keyHint` exported from `@earendil-works/pi-coding-agent`). The task-notification renderer (`renderNotification` in `src/ui.ts`) does this: it draws a Pi tool card (`Box` with `toolSuccessBg`/`toolErrorBg`) and accepts `CardOptions.keyHint?`.
